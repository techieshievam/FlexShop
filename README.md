# 🛍️ FlexShop

A Frontend E-Commerce Website built using HTML and CSS.

## 📌 About The Project

FlexShop is a modern and responsive e-commerce website frontend designed to provide a simple and user-friendly shopping experience.

## ✨ Features

- Modern and clean user interface
- Responsive website layout
- Product collection section
- Clothes collection
- Denim collection
- Shoes collection
- T-shirt collection
- Watches collection
- Product images and details
- Navigation bar
- About section and footer

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📂 Project Structure

```text
FlexShop/
│
├── images/
```
